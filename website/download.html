安装步骤

从未安装过 GitHub 上的应用也没关系，跟着做就好。

  1. ① 下载 APK打开 Releases 页面，在最新版本下方展开 Assets，点击 taixu-v*.apk（arm64）下载。
  2. ② 允许安装首次从浏览器下载安装时，Android 会提示「不允许安装未知应用」，按提示允许浏览器安装应用即可。这是一次性设置。
  3. ③ 完成安装点击安装，等待完成。建议核对 Release 页面提供的 SHA-256 校验值，确认安装包完整。
  4. ④ 首次启动跟随「启程向导」初始化 Linux 环境（需要网络与约 1–2 GB 存储空间），然后按文档配置你的第一个模型服务商。
升级版本直接覆盖安装即可，本地会话与配置会保留。稳妥起见，建议在升级前先用「设置 → 备份」导出一次本地数据。

安装前后的常见问题

为什么不在应用商店？
太墟目前通过 GitHub Releases 分发。仓库开源，安装包与源码同源，Releases 页面可查历史版本与校验值。

下载哪个文件？
选择名称含 arm64 的 APK。太墟仅支持 64 位 ARM 设备（近几年的主流手机基本都是）。

安装后需要多少空间？
APK 本身约几十 MB；首次安装 Linux RootFS 需要网络与约 1–2 GB 存储，后续构建项目还会占用更多。建议预留 5 GB 以上空间。

安装失败怎么办？
确认系统为 Android 10+ 且为 ARM64 设备；下载中断会导致安装包损坏，重新下载后再试。更多问题见常见问题。
