Bot 记忆

每个 Bot 有一份属于自己的 Markdown 记忆。它跨会话生效：你告诉过它的事，下次私聊它还记得。

记忆是怎么工作的

  • 记忆以 Markdown 文本形式保存在 Bot 身上，每次和它对话时都会注入上下文，相当于「随身笔记」。
  • Bot 在对话中会自己往记忆里沉淀值得记的内容（你的偏好、项目背景、约定等）。
  • 记忆是完全开放的：你能看，也能改。

查看与编辑记忆

  1. 打开 Bot 的记忆面板

    在 Bot 详情或对话菜单中进入「记忆」。

  2. 直接编辑

    它就是一篇 Markdown 文档，删掉不对的、补充想要的，保存即生效。

  3. 看历史、可恢复

    每次修改都有版本历史与差异对比，改坏了可以恢复到任一历史版本。

后台修改冲突
如果 Bot 正在后台任务中更新记忆，而你我这边同时编辑，保存时会提示冲突——按提示选择保留哪一边即可，不会静默覆盖。

什么值得记，什么不值得

适合进记忆 ✅不适合 ❌
你的长期偏好（「回答用中文」「代码带注释」）一次性任务的细节（本会话里说清就行）
项目背景、技术栈、目录结构约定频繁变化的状态（这些在工作区文件里）
团队协作的约定（「提交前必须跑测试」）密钥、密码等敏感信息（永远不要）

小技巧

  • 直接对 Bot 说「记住：以后交付前先自测一遍」，比自己改记忆更自然；说完去记忆面板确认它写对了。
  • 记忆太长会占上下文——定期帮它「断舍离」，删掉过时条目。
  • 多个 Bot 协作时，让主控 Bot 的记忆记录「分工与约定」，团队会更稳。
