常见问题

按「症状」索引。先找到和你情况最像的一条，照着排查；都解决不了再去 GitHub Issues 反馈。

发消息没有反应 / 一直转圈

消息发出去就没动静了

  • 检查模型服务商是否配置完整（Base URL + Key + 模型），见配置模型服务商；
  • 发一句「你好」测试：能回说明配置没问题，是任务本身的问题；
  • 网络环境能否访问该服务商（境外服务需要相应网络条件）；
  • 看过程链是否停在「等待审批」——有张卡片在等你确认。

回复到一半停住

  • 多为网络波动导致流式中断，点「继续」即可；
  • 服务商限流（429）时稍等重试。

模型相关报错

报错处理
401 鉴权失败Key 错误或失效：重新完整复制粘贴；去服务商后台确认 Key 状态。
402 / 余额不足服务商账户充值。
404 模型不存在模型 ID 写错了，用「获取模型」拉取正确列表。
429 限流免费 / 低档位 Key 常见，降低并发或升级档位。
context length 超限上下文满了：手动压缩一次，或换长上下文模型。

Linux 与终端

RootFS 下载失败 / 很慢

  • 确认剩余存储 ≥ 2 GB；
  • 换更稳的网络，或在设置中切换镜像线路重试。

命令找不到（command not found）

  • 先用包管理器安装：Ubuntu 用 apt install，Arch 用 pacman -S；
  • 不确定包名直接问 AI「在 Ubuntu 上怎么装 xxx」。

终端里中文或符号显示异常

建议安装并切换到 UTF-8 字体环境；一般不影响实际执行结果。

后台与定时任务

任务跑到一半应用没了

  • 完成三件套：允许通知、关闭电池优化、允许自启动（厂商系统额外设置）；
  • 重新打开太墟，未完成的运行可恢复，已成功的步骤不会重跑；
  • 超长任务建议拆成多个节点，节点之间落盘结果更抗中断。

定时任务不准点

Android 后台调度允许延迟，属正常现象；把电池策略放开可以明显改善，见定时计划与后台运行。

存储与内存

存储占用越来越大

  • 大头通常是 RootFS、构建缓存与项目文件：在「乾坤 → 存储」查看分布并清理；
  • 构建产物与旧 APK 可以手动删除。

应用被系统杀掉 / 闪退

  • 同时开太多长任务、构建大项目会占用大量内存，低配设备建议减少并行；
  • 闪退后重开即可恢复会话；频繁闪退请带上机型与复现步骤到 Issues 反馈。

备份与升级

恢复备份后少了东西

对照备份包含范围：项目文件、RootFS、API Key 本就不在备份里，需按迁移清单另行处理。

覆盖安装失败

重新下载完整 APK；仍失败可先备份数据后卸载重装，再恢复备份。

还没解决？

  • 到 GitHub Issues 搜索或新建反馈，附上：机型、系统版本、太墟版本、复现步骤与截图；
  • 应用内的日志导出功能可以一键打包运行日志，反馈时附上能大幅加快定位。
