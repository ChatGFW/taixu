终端与 Linux 环境

太墟的终端不是「模拟出来的界面」，而是通过原生 PTY 创建的真实控制终端：Ctrl+C 能中断、作业控制能用、退出码是真的。

打开与使用终端

  1. 进入「终端」

    默认进入当前 Linux 发行版的 shell（通常是 bash）。

  2. 像用电脑上的 Linux 一样用

    输入命令、Tab 补全、上下键翻历史，都和标准终端一致。

  3. 多会话

    可以同时开多个终端会话，互不干扰；右上角可切换。

不想背命令也没关系：去智枢告诉 AI「帮我在终端里查看磁盘占用」，它会替你执行，你只需要看结果。

新手常用命令

想做什么命令（Ubuntu / Debian）
看看现在在哪个目录pwd
列出文件ls（详细： ls -la）
进入某个目录cd 目录名
安装软件apt update && apt install 软件名
查看磁盘占用df -h
中断当前程序Ctrl + C
Arch / Kali 等 发行版
包管理命令不同：Arch 系用 pacman -S 软件名，Alpine 用 apk add。不确定时直接问 AI。

管理 RootFS（Linux 环境）

  • 安装：在「乾坤 → Linux」中从镜像源安装发行版（默认推荐 Ubuntu 24.04）。
  • 共存与切换：多个发行版可以同时安装，随时切换当前环境。
  • 回滚：升级或折腾坏了可以回滚到之前的状态。
  • 持久化目录：重要目录可以绑定保存，切换 / 回滚时数据不丢。

访问手机文件

把 Android 共享存储（如 Download 文件夹）挂载进 Linux 后，终端和 AI 都能直接读写手机里的文件；在文件管理器里也能看到 Linux 侧产出的文件。

SSH：把任务带到远程

  • 配置 SSH 服务器后，可以把命令执行环境切到远程 Linux，把手机当作遥控器。
  • 配合 SFTP 可以浏览与传输远程文件。
  • 注意：手机宿主能力（通知、安装 APK 等）仍作用于本机，不随 SSH 切换。
