管理模型与默认设置

你可以同时接入多家服务商、几十个模型：给不同任务选不同的模型，在会话里随手切换，也可以把整套配置导出迁移到新手机。

设置默认模型

在「乾坤 → 模型服务」中选择某个服务商下的模型，设为默认模型。之后新建会话、Bot、工作流节点默认都使用它，不用每次手动选。

选默认模型的建议
日常对话与写码选一个能力均衡的模型即可；便宜快速的模型适合跑工作流里的批量小任务。太墟内置了主流模型的参数与上下文信息，正常情况下无需手工配置。

会话内临时切换

对话界面顶部（或输入区旁）的模型选择器可以在会话中途换模型：同一个会话里，前半段用 A 模型、后半段切到 B 模型，上下文会带过去，不会从头开始。

上下文与压缩

  • 每个模型有自己的上下文窗口（能「记住」的对话长度）。对话太长时，太墟支持自动压缩：把历史内容浓缩成摘要再继续，任务不中断。
  • 也可以在会话菜单里手动压缩，或在长任务前主动压缩，给新内容腾空间。
  • 超大工具输出会自动落盘存档，不会撑爆上下文。

查看用量

太墟会统计每次请求的 token 用量。在会话的用量面板可以按会话、按模型查看消耗，方便对照服务商账单、发现「哪个任务烧钱最多」。

模型档案：导出与迁移

换手机或重装时，不用重新手填所有服务商：

  1. 导出

    「乾坤 → 模型服务 → 模型档案」中导出 JSON 文件，可通过系统分享保存或发送。

  2. 导入

    在新设备上导入该 JSON，选择「复制」或「更新」已有配置，预览确认后完成迁移。

档案默认不含密钥
导出的模型档案默认不包含 API Key，到新设备需重新粘贴。显式选择「包含凭据」导出时 Key 会以明文出现在文件里，请妥善保管、用完即删。
