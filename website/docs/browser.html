浏览器与网页自动化

太墟内置一个多标签浏览器：你可以正常用它上网，也可以把它交给 AI——读页面、点按钮、查资料，都是真实执行。

自己用：一个够用的内置浏览器

  • 多标签浏览，地址栏输入网址即可；页面在应用内打开，不必来回切换 App。
  • 配合「悬浮助手」，可以边看网页边问 AI。

交给 AI：让网页进入执行链

AI 拥有 Browser 工具（内置预设之一），可以直接操作浏览器完成网页任务：

打开 xxx 官网，找到最新版本的更新日志，把要点总结成 5 条。

执行时你会看到它依次打开页面 → 读取内容 → 汇总的完整过程链；涉及导航或交互的操作同样受审批策略约束。

典型的网页任务
查资料并汇总、对比多个页面信息、监控某个页面的变化（配合工作流定时运行）、按步骤完成网页上的查询流程。

进阶：调试与自动化能力

对开发者而言，内置浏览器还提供了一套调试面板：

能力用途
页面 Hook在页面上下文中注入脚本，观察或修改页面行为。
CDP 断点基于 Chrome DevTools 协议的断点调试。
网络时间线查看页面发起的所有请求，排查接口问题。
Fetch 拦截Worker 级拦截与检查网络请求。

这些能力默认不影响普通浏览；需要时再开启即可。

常见问题

  • AI 打不开某个网页：确认设备能访问该站点；部分站点有反爬或登录要求，可先手动登录一次再让 AI 操作。
  • 页面内点击不生效：个别页面结构复杂，把目标描述得更具体（「点右上角的登录按钮」），或让 AI 分步执行。
  • 想接入更多网页能力：通过 MCP 添加第三方浏览器扩展服务器，见工具与 MCP。
