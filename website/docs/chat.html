智枢对话基础

智枢是太墟的主对话界面。它和普通聊天应用最大的不同：这里的回复不只是文字，还有真实的思考、工具调用与执行结果。

发送消息

  • 底部输入框输入内容，点击发送；支持换行与 Markdown 展示（代码高亮、表格、公式、流程图）。
  • 多模态输入：可以附加图片（截图、界面、照片），支持视觉输入的模型能「看图说话」。
  • 每条消息可以点赞 / 点踩反馈，帮助改进。

看懂「过程链」

AI 执行任务时，界面上会出现一条过程链，常见环节包括：

环节含义
思考模型的推理过程（支持 reasoning 的模型），可展开查看。
工具调用AI 读了哪个文件、跑了哪条命令、搜索了什么。点击可看参数与完整输出。
计时每个环节的耗时，方便判断卡在哪一步。
审批卡片危险操作会停下来等你确认，见审批模式与安全。

收货前扫一眼过程链，是确认「AI 到底做了什么」最直接的方式。

停止、继续与出错恢复

  • 停止：任务跑偏时点击停止按钮，随时可以打断。
  • 继续：停下后补充一句要求即可继续，上下文不丢。
  • 中断恢复：应用被杀、断网等意外中断后重新打开，会话与执行状态会恢复，待审批的操作会保留等你处理。

分支与回退

「如果当时换个方案呢？」——不用重开会话：

  • 对话分支：从任意一条历史消息分叉出新走向，原分支保留，随时切换对比。
  • 回退（rewind）：把会话退回到之前的某一步；回退前创建的文件检查点会把工作区文件一起恢复，并检测外部修改冲突。

上下文快满时

长会话、大项目会逼近模型上下文上限。太墟提供自动压缩（把早期内容浓缩成摘要）与手动压缩，压缩后任务继续进行。如果发现 AI 开始「忘事」，主动压缩一次通常就能恢复状态。

更多协作方式

  • 悬浮助手：全局悬浮窗，在任何 App 上方随时唤起对话。
  • WebChat：在手机上开启后，用电脑浏览器输入访问地址 + 配对码，在大屏上继续同一个会话。
  • 快捷指令：把常用提示词保存为按钮，一键发送。
