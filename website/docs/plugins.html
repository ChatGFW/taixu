插件与技能

插件给太墟「加装工具箱」：命令行工具、SDK、本地服务，甚至一整个网页应用，都能打包成 .txplugin 导入使用。

三种插件形态

形态是什么适合
PROCESS 包在 Linux 里安装命令、SDK 与本地服务的扩展包（v2 清单，兼容 v1 工具包）。装 Node、Flutter SDK、自定义脚本等。
WEB 包静态网页应用，在独立 WebView 中打开，可申请少量宿主能力。小工具页面、仪表盘、表单类应用。
原生插件随 APK 编译装配的深度扩展。由开发者随应用发布。

导入一个 PROCESS 插件

  1. 拿到 .txplugin 文件

    来自作者发布页或社区分享。确认来源可信。

  2. 在工具中心导入

    选择文件后，太墟会校验清单、版本、依赖与 SHA-256 完整性。

  3. 安装

    安装过程有进度与日志；失败会自动回滚到旧状态。

  4. 使用

    安装成功后即可在终端调用其命令，或在工具详情中启动。

导入一个 WEB 插件

  1. 进入「设置 → 应用功能插件 → 外部 Web 插件」
  2. 导入 .txplugin（WEB 类型）

    校验通过后出现在列表，点击即可打开页面。

  3. 逐项授权能力

    页面申请的宿主能力（如写剪贴板）会逐项弹窗确认；升级或移除后旧授权自动失效。

装插件前想三秒
PROCESS 插件在 Linux 内以应用身份运行，能力声明用于校验与展示，不构成恶意脚本隔离。只安装可信来源的插件。
