下载与安装

太墟目前通过 GitHub Releases 发布安装包，全程免费。整个过程大约 5 分钟。

先确认你的手机能装

要求说明
系统版本Android 10 或更高（推荐 Android 12+）。
处理器仅支持 64 位 ARM（arm64-v8a）。近几年的主流手机基本都是。
存储空间安装包本身约几十 MB；首次安装 Linux 环境还需约 1–2 GB，建议整体预留 5 GB 以上。
网络首次初始化 Linux 环境需要联网下载镜像；之后本地终端等可离线使用。

安装步骤

  1. 打开 Releases 页面

    用手机浏览器访问 github.com/taixu-lab/taixu/releases，找到最新版本。

  2. 下载 APK

    点击展开该版本的 Assets 列表，选择名称类似 taixu-v1.7.0-arm64.apk 的文件下载。注意选择 arm64 架构的安装包。

  3. 允许安装（仅首次需要）

    点击下载好的文件时，系统会提示「为了您的安全，手机不允许安装来自此来源的未知应用」。点击「设置」→ 允许「来自此来源的应用」，返回后继续安装。这是 Android 的标准安全流程，只在第一次遇到。

  4. 完成安装并打开

    安装完成后打开太墟。第一次启动会进入「启程向导」，见快速上手。

想核对安装包完整性？
Release 页面会附 SHA-256 校验值。在电脑上执行 certutil -hashfile 文件名 SHA256（Windows）或 shasum -a 256 文件名（macOS / Linux），比对两串字符一致即可放心安装。

升级到新版本

  • 直接下载新版本 APK 覆盖安装，不需要卸载旧版，本地会话、配置都会保留。
  • 稳妥起见，升级前建议到「乾坤（设置）→ 备份」导出一次本地数据，见备份与迁移。
  • 如果覆盖安装提示失败，先确认下载的 APK 没有损坏（重新下载），或查看 Release 说明是否有不兼容升级的特殊提示。

安装常见问题

提示「应用未安装」

  • 确认下载的是 arm64 安装包，且文件下载完整（大小与 Release 页面一致）；
  • 下载中断会产生损坏的文件，删除后重新下载；
  • 确认系统为 Android 10+。

担心安全，不敢允许「未知来源」

这个授权只针对「用浏览器安装 APK」这件事本身。太墟的源码在 GitHub 公开可审查，安装包与源码同源构建，Release 页面提供校验值。

能装应用商店版吗？

暂未上架应用商店。请始终从官方 GitHub Releases 下载，不要使用第三方转载的安装包。
