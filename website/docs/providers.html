配置模型服务商

「服务商」= 接口地址（Base URL）+ API Key。配好它，太墟里的所有对话、Bot、工作流就都有了「大脑」。

支持哪些服务商

太墟支持三类模型接口协议，市面上主流服务基本都能接入：

协议适用服务一句话说明
OpenAI Chat CompletionsOpenAI、DeepSeek、SiliconFlow、各类 OpenAI 兼容中转站、Ollama / llama.cpp 本地服务最通用的协议，绝大多数「OpenAI 兼容」服务都用它。
OpenAI ResponsesOpenAI 新版接口及兼容实现OpenAI 较新的接口形态。
Anthropic MessagesClaude 官方 API 及兼容网关Claude 系列模型使用。

添加一个服务商（以 DeepSeek 为例）

  1. 获取接口地址与 Key

    在服务商官网创建 API Key（见快速上手第 2 步）。官方服务的 Base URL 在其 API 文档首页都能找到。

  2. 进入「乾坤」→ 模型服务 → 添加

    选择协议类型，粘贴 Base URL 与 API Key，命名保存。

  3. 拉取模型列表

    点击「获取模型」自动拉取；列表拉不到时也可以手动填写模型 ID（如 deepseek-chat）。

  4. 测试连通

    保存后在智枢发一句「你好」，有回复即成功。

中转站怎么填？
「OpenAI 兼容」的中转站通常给你一个形如 https://xxx.com/v1 的地址和一个 Key：协议选 Chat Completions，把两者填进去，再拉取模型即可。

密钥安全须知

  • API Key 保存在应用侧安全存储中，不会进入工作区文件，也不会随对话发送给模型。
  • 不要把 Key 发给别人、截图分享，或写进项目代码提交到 Git。
  • 怀疑泄露时，立刻去服务商后台删除旧 Key 并重新生成。

常见报错

现象原因与处理
401 / 鉴权失败Key 粘贴不完整或已删除失效；重新复制粘贴，注意首尾不要带空格。
402 / 余额不足服务商账户欠费，充值后重试。
404 / 模型不存在模型 ID 拼写错误，或该服务没有此模型；用「获取模型」拉取正确名称。
429 / 请求过快触发服务商限流，稍等重试即可。
连接超时检查网络；境外服务需要可用的网络环境；本地模型检查电脑是否同一局域网、防火墙是否放行。
回复为空或乱码协议类型选错了（如把 Anthropic 服务配成 Chat Completions），改用匹配的模板重建。
