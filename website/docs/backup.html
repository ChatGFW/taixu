备份与迁移

换机、重装、升级大版本前，花两分钟做一次备份。备份是一个 ZIP 文件，可以自己保存到任何地方。

创建备份

  1. 进入「乾坤 → 备份」
  2. 选择导出

    应用会打包本地数据并生成 ZIP，通过系统分享保存到网盘、电脑或直接发送。

  3. 妥善保存

    建议按日期命名（如 taixu-backup-20261031.zip），与重要文件一起管理。

备份包含 / 不包含什么

✅ 包含❌ 不包含（需另行处理）
会话与对话记录Linux RootFS（重新安装即可）
Bot 配置与记忆工作区里的实际项目文件
工作流与定时计划API Key 与自定义请求头
技能资源、附件、可移植偏好Git Token 等凭据
最容易被忽略的三样
① 工作区项目文件（用 FTP / 共享存储 / Git 远程另行备份）；② API Key（重新粘贴即可）；③ RootFS（重装，无需迁移）。

恢复备份

  1. 导入备份文件

    「乾坤 → 备份 → 恢复」选择 ZIP。

  2. 预览确认

    恢复前会列出将要新增的数据；已有会话不会被覆盖，只做合并。

  3. 完成恢复

    打开智枢确认会话与配置回来了，再重新粘贴 API Key。

换机迁移完整清单

  1. 旧手机：导出本地备份 ZIP；
  2. 旧手机：导出模型档案 JSON（「模型服务 → 模型档案」，默认不含 Key，敏感文件传完即删）；
  3. 旧手机：把工作区项目推到 Git 远程，或打 ZIP 传走；
  4. 新手机：安装太墟 → 恢复备份 → 导入模型档案 → 重新配置 Key → 重装 RootFS → 克隆回项目。
