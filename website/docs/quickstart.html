快速上手：第一条 AI 任务

从安装完成到让 AI 真正替你做一件事，只需 5 步。本页以「DeepSeek」为例配置模型（任何一家都可以），全程不需要任何命令行知识。

第 1 步：初始化 Linux 环境

  1. 打开太墟，进入「启程向导」

    首次启动会自动进入向导；之后也可以在「乾坤（设置）→ Linux」中重新进入。

  2. 选择发行版

    直接用推荐的 Ubuntu 24.04 LTS 即可——它资料最多、软件最全，对新手最友好。想尝鲜以后随时可以再装其他发行版。

  3. 等待下载完成

    向导会从镜像源下载并校验 RootFS（约 1–2 GB，视网速几分钟到半小时）。确保 Wi-Fi 稳定、电量充足。

下载失败？
多为网络波动所致：换个网络重试，或在设置里切换镜像线路后重新安装。

第 2 步：申请一个 API Key

太墟本身不带模型，需要接入一家「模型服务商」。以 DeepSeek 为例：

  1. 注册并充值

    访问 DeepSeek 开放平台（platform.deepseek.com），注册账号，充值几元人民币即可起步。

  2. 创建 API Key

    在平台的「API Keys」页面点「创建」，复制生成的一长串字符。它只显示一次，立刻复制保存好。

用别家可以吗？
可以。OpenAI、Claude、Gemini、SiliconFlow、各类 OpenAI 兼容中转站，甚至电脑上的 Ollama 本地模型都可以，详见配置模型服务商。

第 3 步：把服务商配置进太墟

  1. 进入「乾坤」→ 模型服务

    点击添加服务商，类型选择与所配平台匹配的模板（如 DeepSeek）。

  2. 粘贴接口地址与 API Key

    用模板时地址已自动填好，只需粘贴你的 API Key，保存。

  3. 拉取模型列表并选择模型

    点击「获取模型」或手动填写模型名（如 deepseek-chat），把它设为默认模型。

配置完成后发一句「你好」测试连通性，能正常回复即配置成功。

第 4 步：发出第一条消息

回到智枢（对话主界面），像用普通聊天应用一样输入：

帮我在工作区创建一个 hello.sh，内容是打印「你好，太墟」，然后运行它给我看结果。

你会看到 AI 的过程链：它先思考，然后调用工具创建文件、执行脚本，最后汇报结果。过程中如果涉及需要审批的操作，会弹出确认卡片，你点「允许」它才继续。

多给「可验证」的任务
「写个脚本并运行」「建个文件并展示内容」这类任务有真实结果可看，最适合体会太墟和普通聊天应用的区别。

第 5 步：养成三个好习惯

  1. 用「工坊」装项目

    把要处理的代码、文档放进一个工作区项目，AI 的每一步操作都围绕它进行，结果可查可回退。

  2. 先看过程再收货

    智枢会展示 AI 的思考与工具调用记录，收货前扫一眼它做了什么，是保证质量最简单的方法。

  3. 允许通知 + 电池白名单

    长任务在后台运行时，这两项设置能大幅降低被系统中断的概率，见定时计划与后台运行。

遇到问题？

  • 发消息没有回复 → 见 常见问题 的排查清单；
  • 模型报 401 / 余额不足 → 检查 Key 是否粘贴完整、账户是否有余额；
  • 想系统了解某个功能 → 左侧目录按主题组织，随时查阅。
