介绍：太墟是什么

太墟（TaiXu）是一款 Android 应用：它在不获取 Root 权限的前提下，在你的手机里运行一个真实的 Linux 环境，并让 AI Agent 在这个环境里替你做事——写代码、跑命令、操作文件、构建 App，直到交付结果。

一句话理解太墟

如果把普通 AI 聊天应用比作「一个会说话的顾问」，太墟更像「一个有电脑、有工具、能动手的员工」：你告诉它目标，它会规划步骤、调用工具、执行命令、检查结果；遇到风险操作会先征求你的同意，中断了也能从断点继续。

这一切发生在手机沙盒里的 Linux 中——进程是真的、文件是真的、命令的报错也是真的，所以 AI 拿到的反馈是可信的。

它能做什么

  • 跑一个真实的 Linux：支持 Ubuntu、Debian、Arch、Kali 等 10 种发行版，用 apt / pacman 装软件，跟在电脑上用 Linux 一样。
  • 让 AI 替你执行任务：读写工作区代码、运行测试、调用工具（浏览器、Git、数据库等），完成后给你可验证的产物。
  • 组建 Bot 团队：创建不同人格、不同模型的 Bot，在群聊里 @ 它们分工协作。
  • 把重复工作变成工作流：用可视化流程图编排「命令 → AI → 审批 → 构建交付」，还能定时运行。
  • 写 App、构建 APK：导入或克隆项目，在手机上直接构建 Android / Flutter 应用并安装。

四个主要入口

入口是什么你会在里面做什么
智枢AI 对话主界面发消息、下任务、看 AI 的思考与工具调用过程、审批危险操作。
终端真实 Linux 终端自己敲命令，或观察 AI 执行命令的结果。
工坊项目工作区管理项目文件、浏览源码、查看改动、构建与安装 APK。
乾坤系统设置配置模型服务商、Linux 环境、工具权限、备份等。

几个会反复出现的术语

术语解释
RootFSLinux 系统的根文件系统，可以理解为「装好的 Linux 系统」。首次使用需要联网下载，APK 里不内置。
服务商 / Provider提供 AI 模型的服务，如 DeepSeek、OpenAI、Claude，或任何兼容 OpenAI 接口的中转站、本地模型。配置一个「接口地址 + API Key」即可使用。
Agent能自主调用工具、循环「思考 → 行动 → 验证」的 AI，而不只是回答文字。
Bot带固定人格、指定模型和长期记忆的智能体，可以反复复用。
MCPModel Context Protocol，给 AI 接入外部工具的标准协议，可以接浏览器自动化、数据库等。
工作流把多个步骤（命令、AI、审批）连成流程图，可保存、复用、定时执行。
