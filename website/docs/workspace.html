工坊与 Git

工坊承载项目：新建、导入或克隆代码，浏览源码、构建 APK；Git 工作台让 AI 的每一步改动都有迹可循。

把项目放进工坊

  1. 新建空项目

    适合从零开始的新想法。

  2. 导入本地 ZIP

    把电脑上的项目打包成 ZIP 传到手机后导入（已内置 Zip Slip 路径攻击防护）。

  3. 克隆 GitHub 仓库

    粘贴仓库地址直接克隆；私有仓库需要配置 Token，见下文 Git 部分。

浏览与检查代码

  • 源码树：按目录浏览项目文件，点开即看代码。
  • 行级 Diff：AI 改了哪些文件、改了哪几行，逐处可查。
  • 配合智枢里的「过程链」，每次交付都能核对到具体改动。

构建与安装 APK

  1. 触发构建

    在项目页选择构建目标（Android / Flutter），构建在 Linux 沙箱内后台进行。

  2. 等待产物

    构建日志实时可看；成功后得到 APK。

  3. 签名并安装

    按引导完成签名，可直接安装到本机（首次需授予「安装应用」权限）。

构建需要空间与时间
Android 构建工具链体积较大，首次会下载依赖，建议预留充足存储，并在 Wi-Fi 与充电状态下进行。

Git 工作台

功能说明
改动 / 暂存 / 提交查看变更、选择性暂存、写说明提交。
AI 提交说明让模型根据改动自动生成提交信息。
分支 / 标签 / 提交图分支管理与历史可视化。
推送预览push 前先看将要推送的内容，确认后同步远程。

私有仓库的 HTTPS Token 加密存储在应用内；同样地，不要把 Token 写进代码或提交历史。

让 Git 为 AI 兜底
在让 AI 大改之前先提交一次当前状态；改完不满意可以整体回退——这是最简单可靠的「后悔药」。
