无 Root Linux

基于 PRoot 运行 ARM64 Linux 用户空间，从 OCI 镜像安装并校验 RootFS，无需任何 Root 权限。

Agent Harness

流式推理、工具调用、视觉输入、任务计划与上下文压缩，让模型从「回答问题」走向「完成任务」。

Bot 团队

为 Bot 设定人格与模型，在群聊中分工协作。任务独立运行、随时续办，完成后回报结果。

可视化工作流

DAG 编排命令、Agent、构建与人工审批，支持条件分支、并行执行与定时计划。

原生 PTY 终端

JNI 原生终端，支持作业控制、Ctrl+C 与多会话，直接操作真实 Linux 进程。

MCP 工具生态

内置浏览器、SQLite、Git 等预设，支持 STDIO 与 HTTP 远程 MCP 服务器，按需发现与调用。

工坊与构建

导入项目、浏览源码、查看行级 Diff，沙箱内构建 Android / Flutter 并签名安装 APK。

安全与可恢复

分级工具审批、文件检查点、对话回退与会话恢复；密钥使用应用侧安全存储。

Linux Runtime

手机里，真的在跑 Linux。

基于 PRoot 的 ARM64 Linux 用户空间，从 OCI 镜像安装并校验 RootFS。多发行版共存、切换与回滚，还能把 Android 共享存储挂载进沙箱。

  • 10 种发行版配置Ubuntu 24.04 默认，另有 Debian、Arch、Kali、Fedora 等。
  • 多环境管理安装、切换、回滚，持久化目录绑定随环境保留。
  • 真实终端原生 PTY 会话，包管理与脚本执行和真机无异。
