前往 Issues ↗
需要 Root 或解锁 Bootloader 吗？+

不需要。Linux 环境基于 PRoot 在用户态运行，不依赖 Root 权限；宿主自动化能力则取决于你是否授予无线 ADB、Shizuku 或无障碍等权限。

支持哪些设备？+

当前仅支持 arm64-v8a 架构、Android 10（API 29）及以上，推荐 Android 12+。复杂 TUI 与重型编译会受到设备性能、内存与 PRoot 兼容性影响。

为什么 RootFS 不随 APK 提供？+

镜像体积大且更新频繁，因此从 OCI Registry 按需下载并校验。这样支持多发行版共存，也让 APK 保持相对轻量。

可以连接本地模型吗？+

可以。任何提供 OpenAI-compatible Chat Completions 或 Responses 端点的服务都可以接入；沙箱内或局域网中的 llama.cpp、Ollama 类型服务同样适用。

能替代电脑开发吗？+

它不是电脑的替代品，而是把验证、调试与轻量构建带到移动场景。重型编译与长任务仍更适合电脑或远程 Linux，太墟也可以通过 SSH 连接过去。

备份会包含哪些数据？+

本地 ZIP 涵盖会话、记忆、计划、技能资源与可移植偏好；不包含 RootFS、工作区实际文件、API Key、自定义请求头与会话附件。模型档案可单独导出，选择包含凭据时会以明文写入，需要自行保管。
