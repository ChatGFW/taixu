# 远程 Linux 执行环境

在「Linux 系统管理」中点击「添加系统」，可选择本地安装或连接远程服务器。

远程连接需填写名称、主机/IP、SSH 端口、用户名和已存在的远程工作目录。服务器必须启用 SSH 与 SFTP，并允许该用户访问工作目录。支持密码认证，以及粘贴或通过系统文件选择器导入 PEM/OpenSSH 私钥；加密私钥可填写口令。

首次连接会在发送认证凭证前显示 SHA-256 主机指纹。与服务器提供的指纹核对并确认后，应用验证认证及工作目录，测试成功不会保存配置；点击保存后验证并保存配置，**不改变主系统**。此后固定该指纹，发生变化时拒绝连接；需要核验后移除旧配置并重新添加。

## 主系统与聊天侧边栏

**全局主系统固定为本机 PRoot。** 连接档案不能再被设为「主系统」；读档时若发现历史远程 primary，会原子清回本机并保留档案。首页、工坊、系统状态、本地插件/挂载入口始终使用本机。

远程对话从**聊天侧边栏「远程服务器」分区**进入：每台已保存的服务器一组会话，分组旁「+」新建绑定该服务器的对话（工作区 `/workspace`，对应远端配置工作目录）。创建时把执行目标与连接档案身份写入会话 `executionTargetJson`；不会调用 `RemoteServerRepository.select`。后续 `base`、`process`、`read`、`write`、`edit` 及 MCP STDIO 都使用同一服务器；重启与回退分支继续使用此记录，子任务继承父会话目标和工作区，独立管理连接和进程。修改绑定档案后，新连接与子任务会拒绝启动，需新建会话；不会用相同档案 ID 连接另一主机。

顶部「新建会话」与本机「项目」分区仍创建本机会话。切换前台会话即切换执行环境，无需切换全局主系统。侧栏不添加本地/云端徽章；服务器分组本身即环境入口。远程绑定会话不会进入本机项目/最近分区，避免 `/workspace/...` 路径误挂到同名本机项目。

本地会话与终端创建先等待已保存的发行版选择加载，避免把启动时临时的 Ubuntu 默认值保存为执行目标；无需等待 RootFS 完成启动。运行时就绪后使用当前发行版。SSH 会话与设置探测不等待本地选择或 RootFS。新终端默认本机；已绑定远程的终端记录仍按保存的目标恢复。

数据库升级至 56 时标记为 `unbound` 的历史会话来自尚无 SSH 功能的版本，首次继续执行时绑定当前本地发行版并原子保存，不读取远程默认选择；之后重启、分支和子任务复用该绑定。55 → 56 保留已经记录的对话目标，新增终端主机身份。旧远程终端配置不自动重连；新终端保存完整的无凭证连接身份，重启后校验档案，发生变化则拒绝连接。目标记录不含认证凭证；凭证仍只在加密仓库中。连接存档解密或读取失败时进入不可用状态，不降级为本地。用户明确选择本地后才恢复设置写入，并在不备份目录保留原损坏存档。

便携备份不导出会话中的连接身份；恢复历史会话标为 `restore-required`，需新建会话重新明确执行环境，与版本升级的本地历史兼容分开处理。MCP 检查、在线状态、工具 schema/注解缓存和失败退避按执行环境隔离；编辑档案或切换本地发行版后不复用旧环境的进程和工具元数据。

终端逐条恢复已保存记录。档案被删除、身份发生变化或暂时无法连接的记录保留原执行目标，并在终端页显示失败原因，可重试或仅移除本机记录；其他终端继续恢复，没有可用终端时允许在本机创建新终端。取消恢复或资源清理尚未确认时仍停止创建，避免重复分配资源。绑定会话关闭后回收该会话的 MCP schema、错误、退避、在线状态与发现锁，其他会话缓存保留；独立设置探测仅保留每个 MCP 服务最近使用的执行目标元数据。

未关联项目的远程会话使用配置的工作目录。项目 `/workspace/demo` 映射为 `<远程工作目录>/demo`，子目录需已存在；不会复制手机项目文件。文件工具限定在该会话的远程工作区，命令则具有 SSH 用户在服务器上的实际权限。运行前沿用已有审批和 PLAN 规则。

系统管理页提供本地发行版管理与 SSH **连接档案**列表（新增、编辑、移除）。移除仅删除应用保存的配置与凭证，不删除服务器文件；已建立的远程会话应结束后重新在侧边栏选择环境。密码、私钥和口令加密保存于 Android 不备份目录，不进入模型上下文。

当前提供命令、后台进程、SFTP 文件操作、协议子进程与原生 SSH PTY 终端。远程 PTY 复用 Termux 渲染层，支持输入、尺寸变化和控制序列；默认在服务器工作目录启动，逻辑 `/workspace` 路径映射到远端。远程下载、输出产物及构建脚本绑定适配器暂缺，相关工具明确报错；可按现有审批策略用远程命令执行服务器已有的构建工具。Android 宿主、浏览器及手机特权工具仍作用于手机。

停止远程进程先发送 TERM，必要时 KILL，等待退出确认；未确认则保留资源并报错，允许重试。网络断开或自行脱离 SSH 会话的后代进程无法保证被回收，服务器本身仍负责进程权限与生命周期。

`SshRemoteIntegrationTest` 使用本机临时 SSH/SFTP 服务验证密码与加密 RSA 私钥、认证前指纹校验、文件路径边界、读写编辑、stdout/stderr 与退出码、超时和后台停止。测试不连接真实远程服务器，不调用模型；Android 真机网络、厂商密钥库与服务器兼容性仍需设备验收。

## 首页、系统状态与工坊

这三个入口始终显示**本机**内容（主系统不可再切到 SSH）。连接档案变更不会把首页换成远程指标页。远程系统概览 / SFTP 工坊独立入口不在本切片；远程能力通过绑定该服务器的聊天会话使用。

本机首页及系统状态继续采集手机上的发行版、架构、内核、内存、存储等。本地工坊使用本机项目表与构建管线。存储挂载、插件中心与本地 LLM 管理入口始终可用。

UI 连接获取使用仓储锁内的配置/凭证快照，防止编辑档案时混用旧主机与新凭证；失败的资源清理保留到下一次访问重试，同一连接档案的 UI 操作串行执行。

## 能力矩阵（本地 PRoot / SSH 远程）

工具按 `ExecutionEnvironment` 既有能力槽（`artifacts` / `downloads` / `buildBindings` / `supportsSharedLocalServices`）判定支持范围；远程环境未覆写这些槽，即取接口默认值（`null` / `null` / `null` / `false`）。SSH 专属路径映射依据会话绑定的后端类型处理。

| 能力 | 本地 PRoot | SSH 远程 | UI / 行为 |
| --- | --- | --- | --- |
| 命令执行、文件读写编辑 | ✅ | ✅（SFTP，限远程工作区） | 会话固定执行环境 |
| 输出产物 `artifacts` | ✅ | ❌（null） | 相关工具明确报错 |
| 下载 `downloads` | ✅ | ❌（null） | 相关工具明确报错 |
| 构建脚本绑定 `buildBindings` | ✅ | ❌（null） | 相关工具明确报错 |
| 共享本地服务 `supportsSharedLocalServices` | ✅ | ❌（false） | 构建 / 子智能体等仍绑本地的服务禁用 |
| 存储挂载（PRoot `-b`） | ✅ | ❌ | 挂载仅本机；主系统恒本机后入口始终可用 |
| 原生终端渲染 | ✅ | ✅（SSH PTY） | 新终端默认本机；已保存远程终端按记录恢复 |
| 发行版安装 / 多系统管理 | ✅ | ❌ | 系统管理页的本地系统条目仅对本地生效 |
| 插件 / 底层工具安装（llama.cpp、QEMU 等） | ✅ | ❌ | 安装类调用仍校验本地后端 |

MCP STDIO 工具是「全局配置 + 按执行环境执行」：工作目录及 Git MCP 的 `--repository /workspace/...` 转为当前环境实际路径，远程发现不等待手机 RootFS。STDIO 的 `command` 必须在服务器上已存在——远程环境下先在会话工作目录探测 `command -v`，缺失时健康检查返回实际主机名及原因。

本机新建会话的项目选择器使用本机项目目录。远程会话由侧边栏按服务器创建，首期扁平绑定 `/workspace`。模型档案等应用配置继续可用。
