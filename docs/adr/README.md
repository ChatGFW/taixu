## 写作约定

- 状态只用三种：`已接受` / `已取代` / `已放弃`；提案阶段可加 `提议中`，但合入主干前必须落定。
- 必填段落：背景（Context）、选项（Options）、决策（Decision）、影响（Consequences）、验收（Acceptance）。
- 「选项」里必须写出被拒绝的方案和拒绝理由，否则后人无法判断是否值得重开。
- 影响必须包含代价与回滚方式；只写收益的 ADR 视为未完成。
- 代码里的关键常量、门禁与 ADR 对不上时，以代码为准并回来修正 ADR，不允许两份事实并存。
